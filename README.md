# quick.ha.mr
quick.ha.mr ("Quick Hammer") is a very simple browser extension for Mozilla Firefox and Google Chrome that allows you to quickly compress a given link using [PortalRunner's ha.mr](https://ha.mr). It does this by adding a context menu option when right-clicking links.

Do note the files in the `ha.mr` folder are direct copies from the [ha.mr repository](https://github.com/p2r3/ha.mr), and shared under it's MIT license. I do not take credit for them, but I also do not offer fixes or improvements for them. Any issues with the compression itself should be directed there.

The icon has been created on the with the help of the [Bootstrap Icons Iconset](https://github.com/twbs/icons), which itself is shared under the MIT license.
